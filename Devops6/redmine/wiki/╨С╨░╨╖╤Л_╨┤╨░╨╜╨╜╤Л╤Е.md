# Базы данных

[[Wiki|← на главную]]

В проекте 4 базы данных — по одной на микросервис:

| Микросервис | Проект DAL | Начальные данные |
|---|---|---|
| Identity | `Services/Identity/Identity.DAL` | — |
| Purchases | `Services/Purchases/Purchases.DAL` | — |
| Shops | `Services/Shops/Shops.DAL` | 4 магазина по 4 товара (`ShopsDbContext.cs`) |
| Factories | `Services/Factories/Factories.DAL` | 3–4 завода с товарами для разных магазинов (`FactoriesDbContext.cs`) |

* Подход проектирования: **Code First**
* Хранилище: **SQL Server** в Docker (`mcr.microsoft.com/mssql/server`)
* ORM: **Entity Framework Core**
