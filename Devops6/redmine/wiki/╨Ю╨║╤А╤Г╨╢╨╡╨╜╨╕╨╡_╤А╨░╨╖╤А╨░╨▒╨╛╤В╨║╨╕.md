# Окружение разработки и CI

[[Wiki|← на главную]]

Dev-окружение разворачивается одним файлом `docker-compose.yml` (репозиторий Gitea `student/devenv`) на Ubuntu Server:

| Сервис | Образ | Адрес |
|---|---|---|
| Gitea | `gitea/gitea:latest` | http://localhost:3001 |
| Redmine | `redmine` + `postgres:16` | http://localhost:3000 (с хоста — :8080) |
| Drone Server | `drone/drone:2` | http://localhost:8000 |
| Drone Runner | `drone/drone-runner-docker:1` | — |
| Docker Registry | `registry:2` | http://localhost:5000 |

Запуск:
```
cp .env.example .env   # заполнить секреты Drone и OAuth Gitea
docker compose up -d
```

## Конвейер (`.drone.yml`)

Срабатывает на push в `master` (и вручную):

1. **clone** — клонирование из Gitea;
2. **unit-tests** — `dotnet test` для Purchases и Shops (`mcr.microsoft.com/dotnet/sdk:3.1`);
3. **build-and-push** — сборка Docker-образов пяти сервисов и публикация в `localhost:5000/rtuitlab/<сервис>` с тегами `latest` и номером сборки.

Проверить опубликованные образы: `curl http://localhost:5000/v2/_catalog`.
