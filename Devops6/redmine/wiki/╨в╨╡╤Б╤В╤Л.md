# Тесты

[[Wiki|← на главную]]

* **Smoke-тесты** (`*.FunctionalTests`) — проверяют доступность функционала; для запуска нужен работающий RabbitMQ.
* **Модульные тесты** (`*.UnitTests`, xUnit + EF Core InMemory) — покрывают сервисы **Purchases** и **Shops**:
  * `src/Services/Purchases/tests/Purchases.UnitTests`
  * `src/Services/Shops/tests/Shops.UnitTests`

Модульные тесты запускаются в конвейере Drone на шаге `unit-tests`:

```
dotnet test Services/Purchases/tests/Purchases.UnitTests/Purchases.UnitTests.csproj -c Release
dotnet test Services/Shops/tests/Shops.UnitTests/Shops.UnitTests.csproj -c Release
```
